# Target Information Queries

## Overview and Purpose

The `JIT.TargetInfo` struct encapsulates target-specific capability queries for the JIT compiler. Obtained via `JIT.Context.get_target_info()`, this API enables runtime inspection of target hardware features, architecture identification, and target-dependent type support (such as native support for specialized types like `BFloat16`, `Float16`, `Float128`, or `Int128_t`).

Because libgccjit introduces target information querying capabilities starting with ABI version 35, usage of `JIT.TargetInfo` and its associated context method is guarded by the runtime feature flag `JIT.Have_TargetInfo_API`

## ABI Versioning and Feature Guarding

The target information subsystem relies on runtime feature detection rather than compile-time linking assumptions. The entry points are guarded by the `JIT.Have_TargetInfo_API` flag generated by the `Have` template in module `gccjit`.

## The TargetInfo Struct API

`JIT.TargetInfo` follows the library's standard value wrapper design, maintaining an underlying C pointer (`gcc_jit_target_info*`) and providing `nothrow @nogc` operations

### Null-Checking and Lifecycle Management

- `opCast(T : bool)`: Enables idiomatic null-checking (`if (info)`) by returning whether the underlying `m_target_info` pointer is non-null
- `release()`: Releases the `gcc_jit_target_info` instance and nullifies the internal handle

### Query Methods
| Method | Return Type | Description |
|--------|-------------|-------------|
| `cpu_supports(string feature)` | `bool` | Returns true if the specified CPU feature is supported by the target.
| `arch()` | `string` |	Returns the target architecture name as a D string. |
| `supports_type(CType type)` | `bool` | Returns true if the target natively supports the target-dependent `CType`. |

## Internal Package Accessors

For package-internal integration within gccjit, `JIT.TargetInfo` defines package-restricted constructors and getters that bridge the raw C API handles to the D wrapper type.

- `this(gcc_jit_target_info* target_info)`: Wraps a raw C pointer
- `inout(gcc_jit_target_info)* get_target_info() inout`: Retrieves the underlying pointer
